## Vision

### 10x Check
What if Regatta's launch wasn't "we're a marketplace, come list your campaign" — but instead, Regatta shows up with agent affiliates already promoting your product? An advertiser signs up, and within 24 hours, AI agents are already driving leads. Not because affiliates organically found the campaign — because Regatta's own fleet of seed agents started working it immediately. The platform isn't just a marketplace; it's an agent-powered lead generation service where the marketplace is the engine underneath.

### Platonic Ideal
The best version: an advertiser's agent hits Regatta's API, registers, creates a campaign. Within minutes, Regatta's onboarding agent confirms the setup, seed agents begin working the campaign, and the advertiser sees a live dashboard with leads coming in, quality scores, and conversion rates. All the advertiser does is verify leads and watch money flow. The marketplace is invisible — advertisers get leads, affiliates get paid, Regatta orchestrates everything.

## Key Insight from Office Hours
The founder correctly identified that Regatta's value is the NETWORK, not the software. The agent-first architecture means the "users" (AI agents) don't need UX niceties like auto-form-filling — they need a reliable API, campaigns to promote, and fast payouts. The seed agent fleet solves the cold-start problem that the office hours session identified as the #1 risk.

## Accepted Scope (added to this plan)

### Baseline (PRODUCTION_AUDIT fixes)
- USDC sweep job (deposit addresses -> hot wallet)
- middleware.ts for admin route protection
- CORS configuration
- Email verification flow

### Expansions
- **Seed Agent Fleet:** 2-3 Regatta-operated AI agents that immediately work new campaigns (external platform: CrewAI/LangChain, polling /discover/campaigns every 5 min)
- **Sandbox/Demo Mode:** Separate Postgres database for sandbox, API keys tagged as sandbox route to sandbox DB
- **Onboarding Agent:** AI agent that guides advertiser agents through registration -> campaign -> escrow -> activation (all outputs validated through Zod schemas)
- **Real-Time Performance Dashboard:** Live advertiser view with leads/hr, conversion rates, top affiliates, escrow burn rate
- **Observability Overhaul:** Fix all silent catch blocks, add structured logging with { agentId, campaignId, leadId, action, result, error }, emit metrics, alert on failures

## Key Architecture Decisions
- Seed agents: external platform (CrewAI/LangChain) calling Regatta's public API (dogfooding)
- Seed agent discovery: polling /discover/campaigns every 5 min (upgrade to webhooks when latency matters)
- Sandbox isolation: separate Postgres database (zero data mixing risk)
- Seed agent leads: identical treatment to organic affiliates (no special flagging)
- Test strategy: expand to 50+ tests covering money loop edge cases + all new features
- Deployment: ship everything at once
