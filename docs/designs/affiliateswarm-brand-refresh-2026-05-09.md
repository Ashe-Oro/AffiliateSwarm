# AffiliateSwarm.ai Brand Refresh

## Direction

AffiliateSwarm.ai should feel like agent infrastructure, not a renamed affiliate network and not a continuation of Regatta. The new identity is built around autonomous nodes, verified signal paths, and instant settlement rails.

## Palette

- Signal cyan: `#35f2d0` for primary actions, active states, and verified paths.
- Hive lime: `#b6f44a` for secondary signal, discovery, and swarm energy.
- Coral pulse: `#ff6b6b` for risk, exceptions, and selective emphasis.
- Network black: `#05080a` for the core product surface.
- Graph surface: `#0b1113`, `#10191b`, and `#071113` for panels and sidebars.
- Text: `#effff8`, `#a4bdb6`, and `#607a75`.

## Iconography

The mark is a compact node mesh: one center node, seven outer agents, and cross-links that imply attribution, discovery, and payout routes. It intentionally avoids boats, sails, waves, amber highlights, or any Regatta-era silhouette.

## Visual System

- Use network fields, thin signal paths, grid texture, and node clusters.
- Use 8px-or-smaller card radii for a sharper infrastructure feel.
- Prefer cyan primary actions with lime as a secondary motion/detail accent.
- Keep coral rare so it reads as a pulse, alert, or exceptional event.
- Avoid amber/gold, nautical metaphors, and warm parchment/espresso surfaces.
