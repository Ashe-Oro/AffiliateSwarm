# AffiliateSwarm Submission Kit

This folder contains public-safe image assets for AffiliateSwarm directory,
startup, AI-tool, API, and community submissions.

## Instruction File

Use `directory-submission-instructions.md` as the primary contractor handoff.
It contains approved product copy, Venice.ai campaign wording, Google spam
policy guardrails, platform fee-waiver language, and step-by-step submission
instructions.

## Packaged Zip

`affiliateswarm-submission-image-kit.zip` contains this README, the instruction
file, and all image assets listed below. Use it when handing the kit to someone
outside the repository.

## Public-Safety Notes

- All screenshots are public pages.
- No dashboard data, email addresses, API keys, balances, or customer data are
  included.
- The Venice campaign card mentions Venice.ai in text only. It does not use a
  Venice logo or co-branded creative.

## Remaining Founder Inputs

Before handing this to a contractor, provide or confirm:

- Official company email for account creation.
- Password manager instructions.
- Founder name, title, and approved profile links.
- Whether a founder headshot or founder bio may be used.
- Whether paid listings are allowed. Default should be no paid submissions
  without CEO approval.
- Final UTM convention for directory links.
