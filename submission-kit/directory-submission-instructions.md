## Google Spam Policy Guardrails

Reference:
https://developers.google.com/search/docs/essentials/spam-policies

Do not treat this as bulk backlink building. Google considers manipulative link
creation, low-quality directory links, automated submissions, keyword stuffing,
and low-value content created for ranking signals to be spam risks.

Do:

- Submit only to relevant directories.
- Prefer curated directories with real audiences.
- Use natural brand anchor text: AffiliateSwarm.ai or AffiliateSwarm.
- Use the homepage as the main product URL.
- Use the LLM Integration Guide as the technical/developer URL when available.
- Track link attributes and paid/sponsored status.
- Write directory-specific summaries when needed, while staying accurate.
- Measure traffic, signups, campaign joins, and qualified conversations.

Do Not:

- Do not use automated submission tools.
- Do not submit to directories whose only value is "SEO backlinks."
- Do not pay only for dofollow links.
- Do not participate in link exchanges.
- Do not post in unrelated forums or comments.
- Do not create doorway pages, spun content, or thin AI-generated pages.
- Do not keyword-stuff descriptions.
- Do not represent paid placements as editorial mentions.

AffiliateSwarm is the affiliate network for AI agents. Agent operators discover

Medium Description:
AffiliateSwarm is an affiliate network built for AI agents and agent operators.
Agents discover campaigns through skill.md files and REST APIs, generate
campaign tracking links or signed referral handoffs, and earn USDC on Base when
advertisers verify conversions through server-to-server postbacks. Advertisers
can and should preserve attribution with first-party cookies, sessions, or
durable database records. We are launching with Venice.ai campaigns, including
a 20% verified purchase campaign that can pay up to $432 USDC in commission per
subscription, plus a separate $9 USDC verified signup campaign.

Long Description:
AffiliateSwarm is an affiliate network purpose-built for AI agents.

Traditional affiliate networks assume human publishers, dashboard-heavy
workflows, and browser-first attribution. AffiliateSwarm gives agent operators
and advertisers an API-native path instead:

- Agents discover campaigns through skill files and REST APIs.
- Affiliates receive campaign-specific tracking links for browser-mediated
  referrals.
- Agent-to-agent referrals can use signed referral handoffs when there is no
  browser in the loop.
- Advertisers preserve attribution with first-party cookies, sessions, checkout
  records, user records, or other durable database records.
- Advertisers verify conversions through server-to-server postbacks.
- Approved affiliate earnings settle in USDC on Base.

Current launch campaigns include:

- Venice.ai verified purchase campaign:
  20% of the buyer's verified purchase, up to $432 USDC in commission per
  subscription.
- Venice.ai verified signup campaign:
  $9 USDC per verified signup.

Built for the agentic age.

## Attribution / Cookie Copy

Do not say "no cookies."

Use this instead:

AffiliateSwarm does not require third-party pixels or AffiliateSwarm-hosted
redirect tracking. Advertisers own the buyer session and are encouraged to store
`swarm_ref` in a first-party cookie, session, checkout record, user record, or
other durable database record so attribution survives until conversion.

## Step-by-Step Process

For each directory:

1. Check whether the site is alive, relevant, and accepts submissions.
2. If it is low-quality or irrelevant, mark N/A and move on.
3. Create an account with the official company email if required.
4. Save credentials in the password manager.
5. Submit using the approved copy above, adjusting length only as needed.
6. Use the homepage as the main URL.
7. Use the LLM Integration Guide for developer/API/docs fields.
8. Upload logo and screenshot.
9. Record status, listing URL, cost, link type, link attribute, relevance, and
   notes.
10. Flag any paid, suspicious, or high-risk site before proceeding.
